# DOMINION | STANDOFF 2 — Discord Tournament Bot

Первая рабочая версия платформы DOMINION. Основной интерфейс — **кнопки и модальные окна**, а не набор команд.

## Что уже есть

- Автоматическая инициализация PostgreSQL.
- Профиль игрока: ник Standoff 2, рейтинг, победы/поражения, турниры.
- Главная панель DOMINION с кнопками:
  - 👤 Профиль
  - 🏆 Турниры
  - 🎮 Мои матчи
  - 🤖 AI-помощник (если задан OPENAI_API_KEY)
- Админ-панель через кнопку `⚙️ Управление`.
- Создание турнира через форму.
- Регистрация игроков кнопкой.
- Автоматическая сетка 1v1 при запуске турнира.
- Автоматическое создание следующих матчей после подтверждения результата.
- Защита от двойной регистрации и повторного подтверждения результата.
- PostgreSQL для постоянного хранения данных.
- Глобальный обработчик ошибок, graceful shutdown и повторное подключение к БД.

## Важное ограничение MVP

Это **первая рабочая версия**, поэтому турнирный движок сейчас рассчитан на **1v1 single-elimination**. Командные турниры, сезоны, красивые PNG-карточки, рейтинговая система ELO, споры и расширенная карьера игрока закладываются как следующие модули.

## Запуск локально

1. Установи Node.js 24+.
2. Создай PostgreSQL и скопируй `.env.example` в `.env`.
3. Заполни переменные.
4. Выполни:

```bash
npm install
npm run check
npm start
```

## Discord Developer Portal

Создай Application → Bot, скопируй токен. Пригласи бота на сервер с OAuth2 scopes `bot` и `applications.commands`. Для этой версии достаточно права отправки сообщений, встраивания ссылок, использования внешних эмодзи и просмотра каналов; для админских действий роль `ADMIN_ROLE_ID` должна существовать на сервере.

## Railway

Создай проект → подключи GitHub → добавь PostgreSQL → Variables. Railway передаст `DATABASE_URL` сервису. Для долгоживущего Discord-бота нужен обычный **Service**, а не Cron Job.

Минимальные Variables:

- `DISCORD_TOKEN`
- `DISCORD_CLIENT_ID`
- `DISCORD_GUILD_ID`
- `PANEL_CHANNEL_ID`
- `ADMIN_ROLE_ID`
- `DATABASE_URL`
- `OPENAI_API_KEY` (необязательно)
- `OPENAI_MODEL` (необязательно)

После первого запуска бот сам отправит/обновит главную панель в `PANEL_CHANNEL_ID`.

## Безопасность

Никогда не загружай `.env` и токен Discord в GitHub. API-ключ OpenAI также должен храниться только в переменных окружения на сервере.
